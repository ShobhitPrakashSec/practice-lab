# Fullstack Practice Lab

A disciplined, end-to-end full-stack project.

## Objective

Build real, interview-relevant full-stack skills through one evolving production-style project.

## Tech Stack

- Frontend: React + TypeScript + Tailwind CSS
- Backend: Node.js + Express + TypeScript
- Database: PostgreSQL + Prisma
- Auth: JWT (Access + Refresh)

## Execution

- Single repository
- Daily GitHub commits
- Backend-first development
- No scope creep
- No framework hopping

## Project

A task and project management system (mini Jira-style) supporting:

- Authentication
- Projects
- Tasks
- Role-based access

This repository is intentionally structured to support:

- Recruiter review
- Technical interviews
- Junior-level system design discussions
